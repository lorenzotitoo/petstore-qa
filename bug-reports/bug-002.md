# BUG-002 — API permite criação de usuário sem corpo da requisição

**Endpoint:** POST /user

**Tipo:** Validação de entrada

**Severidade:** Medium

**Prioridade:** Medium

**Status:** Open

## Descrição

A API permite o processamento de uma requisição de criação de
usuário mesmo quando o corpo da requisição está vazio.

## Passos para reprodução

1. Enviar uma requisição POST para `/user`.
2. Não informar conteúdo no body.
3. Enviar a requisição.
4. Verificar a resposta.

## Resultado esperado

A API deve rejeitar a requisição devido à ausência do payload
necessário para criação do usuário.

## Resultado obtido

A API retornou HTTP 200 e criou um usuário mesmo sem conteúdo
no corpo da requisição.

## Impacto

A ausência de validação do payload permite a criação de registros
sem os dados necessários.

## Caso relacionado

TC-005 — Criar usuário com body vazio
