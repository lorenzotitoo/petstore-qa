# BUG-003 — PUT /pet cria Pet com ID inexistente

**Endpoint:** PUT /pet

**Tipo:** Validação de comportamento

**Severidade:** Medium

**Prioridade:** Medium

**Status:** Open

## Descrição

O endpoint PUT /pet permite a criação de um novo Pet quando é
informado um ID que não existe.

De acordo com a documentação do endpoint, uma tentativa de
atualização de um Pet inexistente deve resultar em erro HTTP 400
ou 404.

## Pré-condições

Não deve existir um Pet com o ID utilizado no teste.

## Passos para reprodução

1. Informar um ID de Pet inexistente.
2. Enviar uma requisição PUT para `/pet`.
3. Verificar o status da resposta.
4. Verificar o corpo da resposta.

## Resultado esperado

A API deve retornar HTTP 400 ou 404, indicando que o Pet não
pode ser atualizado porque o recurso não existe.

## Resultado obtido

A API retornou HTTP 200 e criou um novo Pet com o ID informado.

## Impacto

O endpoint permite a criação de recursos através de uma operação
destinada à atualização, contrariando o comportamento especificado
para o endpoint.
