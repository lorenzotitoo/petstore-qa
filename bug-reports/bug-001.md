# BUG-001 — API permite criação de usuário com campos obrigatórios vazios

**Endpoint:** POST /user

**Tipo:** Validação de dados

**Severidade:** Medium

**Prioridade:** Medium

**Status:** Open

## Descrição

A API permite a criação de usuários mesmo quando campos que
deveriam ser obrigatórios são enviados vazios.

O comportamento foi identificado nos campos `firstName`, `email`
e `password`.

## Pré-condições

Nenhuma.

## Passos para reprodução

1. Acessar o endpoint POST /user.
2. Informar um payload contendo um dos campos obrigatórios vazio.
3. Enviar a requisição.
4. Verificar a resposta da API.

## Resultado esperado

A API deve rejeitar a requisição e retornar um código de erro
apropriado, informando que o campo obrigatório não foi preenchido.

## Resultado obtido

A API retornou HTTP 200 e criou o usuário mesmo com o campo
obrigatório vazio.

## Impacto

A ausência de validação permite o cadastro de usuários com dados
incompletos, podendo comprometer a integridade dos dados.
